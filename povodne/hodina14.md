# Seriove zapojenie rezistorov

- v seriovo zapojenom obvode je prud rovnaky a meni sa napatie
- ked prejde prud cez hocijaky rezistor, vznika na nom napatie, ktore sa nazyva úbytok napätia
- vyjadrime napatie z ohmovho zakona 
- U = U1 + U2 + U3 + .... Un
- IR = IR1 + IR2 + IR3 + ... IRn
- IR = I(R1 + R2 + R3 + ... Rn)
- R = R1 + R2 + R3 + ... Rn
- pri seriovom zapojeni rezistorov sa vysledny odpor rovna suctu jednotlivych odporov
- v seriovom zapojeni plati ze vysledny odpor je vzdy vacsi ako najvacsi z nich (je sucet)

# Paralelne zapojenie

- pri pararelnom zapojeni suciastok v akomkolvek obvode sa meni prud (su tam uzly) a napatie ostava rovnake
- podla ohmovho zakona:
  - U / R = (U / R1) + (U / R2) + (U / R3) + ... + (U / Rn)
  - U(1/R) = U((1/R1) + (1/R2) + (1/R3) + ... + (1/Rn))
  - 1/R = 1/R1 + 1/R2 + 1/R3 + ... + 1/Rn
- prevratena hodnota vysledneho odporu sa rovna suctu prevratenych hodnot jednotlivych odporov
- pre dva paralelne zapojene odpory plati:
  - R = (R1 * R2) / (R1 + R2)
- v paralelne zapojenom obvode je lepsie pocitat s vodivostou, kde:
  - 1/R = G => G = G1 + G2 + G3 + ... + Gn
